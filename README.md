# Ethereum Smart Contracts

This repository contains basic smart contracts written in Solidity and deployed on the Sepolia Testnet.

## Overview

These contracts were developed and deployed using:
- Remix IDE
- MetaMask (Injected Provider)
- Sepolia Testnet

## Smart Contracts

### 1. Add.sol
- Performs addition
- Performs subtraction
- Uses pure functions

### 2. Hello.sol
- Stores a private message
- Constructor-based initialization
- setMessage() function
- getMessage() view function

## Deployment Details

Network: Sepolia Testnet  
Compiler Version: ^0.8.19  
Deployment Method: Injected Provider (MetaMask)

## What I Learned

- Smart contract deployment lifecycle
- Gas fee transactions
- Difference between pure and view functions
- Interaction with MetaMask wallet
